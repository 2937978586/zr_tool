JSON 格式化与校验工具

美化、压缩、校验 JSON，生成 TypeScript / Java / Go / C# 类型，处理接口调试与日志排查。

JSON 是前后端接口、配置文件和日志里最常见的数据格式。一段没有缩进的 JSON 很难读，一个多余的逗号又会让整个接口解析失败。孜然工具箱的 JSON 工具分类把格式化、压缩、校验和类型生成放在一起，复制粘贴即可得到结果。

常用能力

  • 格式化 / 美化：2 空格或 4 空格缩进，按层级展开，适合接口返回值和配置文件。
  • 压缩：去掉空格与换行，减小体积，便于放进 URL、Header 或数据库字段。
  • 校验与错误定位：提示出错的行列位置，快速找到多余逗号、引号或括号。
  • 类型生成：把 JSON 转成 TypeScript interface、Java 实体类、Go struct、C# 类，省去手写。
  • 格式互转：JSON ↔ YAML、XML、Excel、GET 参数，覆盖常见配置与数据交换场景。

什么时候会用到

联调接口时查看返回结构、排查线上日志、把第三方 API 示例转成项目里的类型定义、把 Excel 配置转成 JSON、把 JSON 配置转成 YAML 给运维使用。对于嵌套很深的对象，可以先用格式化看清层级，再用「JSON 转 TypeScript」生成嵌套 interface。

使用建议

处理敏感数据前请先脱敏；超大 JSON（几十 MB）建议用本地编辑器，浏览器标签页内存有限。工具默认在本地解析，不会把你的 JSON 上传到服务器。

常见问题

关于JSON 格式化与校验工具

JSON 格式化后中文变成 Unicode 转义怎么办？
这是「Unicode 转义」开关或原始数据本身带转义。使用 JSON 格式化时关闭转义，或先用「Unicode 转中文」还原即可。
JSON 校验失败但看不出哪里错？
把 JSON 粘贴到格式化工具，错误提示会给出行列位置；常见原因是末尾多余逗号、使用单引号、注释未删除。
JSON 转 TypeScript 支持嵌套对象和数组吗？
支持。嵌套对象会拆成独立 interface，数组会推断元素类型；字段名含特殊字符时会自动加引号。
在线上工具处理 JSON 安全吗？
本站 JSON 工具在浏览器本地解析，不上传服务器；仍建议不要粘贴包含密钥、手机号等敏感信息的原文。
