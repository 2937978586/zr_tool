站长 SEO 工具箱

上线前自查、日常巡检与域名信息查询，一个页面完成。

网站上线前后，总有一串琐碎但必要的检查：域名什么时候到期、备案是否有效、首页返回 200 还是 301、Title 和 Description 有没有写、Gzip 有没有开、站内有没有死链。把这些检查集中起来，能少装很多浏览器插件。

上线前检查清单

  • 域名与备案：查 Whois 确认到期时间与注册商，查 ICP 备案确认主体信息。
  • 可访问性：用 HTTP 状态码检测看首页、robots.txt、sitemap.xml 是否正常；用 死链检测扫描站内链接。
  • SEO 基础：用 Meta 标签检测检查 Title、Description、Canonical、OG；用 关键词密度做内容自查。
  • 性能：用 Gzip 检测确认文本资源是否压缩；图片侧配合 WebP 与懒加载。
  • 解析与网络：用 DNS 查询、IP 查询、子网计算排查解析与网络问题。

日常巡检建议

每周看一次状态码与死链，每月看一次 Whois 与证书到期时间；发布新栏目后及时更新 sitemap 并提交搜索引擎。工具只做检测与提示，具体修复仍需在服务器或 CMS 中完成。

常见问题

关于站长 SEO 工具箱

Whois 查询结果为什么隐藏了部分信息？
受隐私保护政策影响，注册商可能隐藏持有人姓名、邮箱与电话，只保留注册商、到期时间等公开字段。
状态码检测显示 301 正常吗？
正常。301 表示永久跳转，常见于 HTTP→HTTPS、带 www 与不带 www 的归一化；只要最终落地页返回 200 即可。
Meta 检测能看哪些标签？
Title、Description、Keywords、Canonical、Robots、Open Graph、Twitter Card 以及 H 标签结构。
死链检测会爬取整个网站吗？
按输入的入口抓取同域链接，建议先用栏目页或 sitemap 做小范围检测，避免对服务器造成压力。
